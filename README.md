 Product Service

Product Service is a Spring Boot microservice responsible for managing products in the e-commerce system.

 Features

* Add new product (Admin only)
* Update product details (Admin only)
* Delete product (Admin only)
* View all products (User/Admin)
* Get product by ID (User/Admin)
* Reduce product stock (Admin)

 Security

* Secured using JWT Authentication
* Role-based access

 Tech Stack

* Java
* Spring Boot
* Spring Security
* JWT Authentication
* MySQL
